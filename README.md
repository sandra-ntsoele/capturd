### Marriage Preparation

- **Guided Reflection:** Access curated questions designed to spark intentional conversation.

## Getting Started

```bash
# Clone the journey
git clone [https://github.com/sandra-ntsoele/capturd.git](https://github.com/sandra-ntsoele/capturd.git)

# Enter the ecosystem
cd capturd

# Install the dependencies
pnpm install

# Launch locally
pnpm dev
```
